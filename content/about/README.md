# 阅读与验证约定

这里保存可继续维护的知识，而不是把每次项目对话原样归档。

## 内容单元

- 一篇文章、一本书或一个专题各占一个文件夹。
- `README.md` 是单元入口；可直接写正文，也可组织章节。
- `assets/` 放配图；有独立价值的最小示例放 `examples/`。
- 目录决定归档位置，入口目录决定阅读顺序，标签表达交叉关系。
- 不复制同一正文到多个分类中。需要多入口时添加链接。

## 证据与状态

“点击被系统接受”“官方业务完成”“有记录”“记录完整”是不同结论。涉及实验时，说明测试条件、证据来源及未覆盖范围。用户现场反馈和独立读回核对也分开描述。

Kalibr 书籍由源仓库导入。源文档标记为 draft 的章节在本站仍是草稿；上线不代表进行了新的数学正确性审查。

## 发布边界

工程案例不公开应用厂商、包名、账号、设备序列号、绑定材料、个人心率明细或原始系统诊断包。公开的最小示例只使用明确标注的合成输入，不冒充现场数据。

源书籍保留原项目署名与来源。不因在本站展示而改变原作者权利或额外授予转载许可。

## 更新方式

本站原生文章在本仓库维护。外部书籍回源项目修改，再通过自动构建更新本站。
