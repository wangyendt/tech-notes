# 系统与工程

工程问题通常不是“某段代码能不能执行”，而是多个组件在权限、生命周期和异常场景下能否共同完成一个可验证的目标。

## Android 与可穿戴设备

[免 root 采集可穿戴设备心率：一次 Android 工程闭环](android-wearable-heart-rate/README.md)

从协议分析到可用原型：保留某 App 的设备连接，通过授权系统桥和无障碍完成运动控制，解析本机蓝牙日志流并保留时间戳、零值与数据间隔。

适合关注 Android 权限、数据采集、自动化控制和传感器数据质量的读者。设备与应用均匿名处理；它不是针对任意设备都成立的使用教程。
