# 知识库发布与单向同步

## 决策

新建独立 `tech-notes`，不修改同级旧文档或旧主页仓库。原生文章在 `content/`，Kalibr 正文留在源项目；构建时只读导入书籍子目录。用户已确认公开仓库及书籍全文发布。

## 同步范围

源仓库 `wangyendt/kalibr-camimu-ceres` 的 `master` 分支，仅 `docs/books/kalibr_cam_imu_from_equations_to_ceres`。不导入项目其余文件、不执行源码、不双向回写。

默认每小时检查，比较书籍目录树与本站构建输入的指纹；变化才部署。支持手动强制构建和未来的跨仓库事件，但默认不修改源仓库，也不申请额外令牌。

## 发布检查

严格构建、链接与匿名化检查、公式和导航浏览器验证通过后发布。正文保留证据等级、draft 状态和适用边界。不发布个人健康记录或原始诊断包。


## 2026-10-26 文案与阅读界面修订

首页改为书籍与文章的阅读索引；工程案例按实现、故障和测试组织，删除重复总结，保留实测数字与限制。写作参考 Microsoft / Google 官方文档指南。

阅读主题使用 Zensical modern、浅色导航、无衬线标题、表格与代码的低对比底色，保留深色模式及手机导航。

书籍取消正文内的来源提示，由模板追加页脚；只适配 README 入口与相对链接。每次构建另提供源书目录全部 Git 跟踪文件的确定性 ZIP 和 SHA-256 清单。当前 24 个文件：18 个正文入口/章节/附录 Markdown、1 个素材说明、5 张 PNG。原始项目不修改。

公式渲染增加段落内展示公式兼容：在 Markdown 强调与转义处理之前保护原稿 `$$...$$`，修复引用块及列表中的漏渲染。原始 Markdown 与 ZIP 不改动；测试覆盖代码围栏、行内代码和普通公式。


## 首页标题目录

首页改为按主题分组的统一标题列表，仅用小标签区分书籍与文章。原生内容入口声明 `type: article` 或 `type: book`，标题从元数据或一级标题读取，主题从顶层目录读取。外部 Kalibr 直接从导入的原书读取标题，不改源文件。构建器替换首页的 CONTENT_INDEX 标记；新增、改名和删除条目不再维护另一份首页列表。

当前只自动生成首页索引，不更改专题正文和静态侧栏导航；外部书籍导入仍是既有单源流程。
