# 知识库发布与单向同步

## 决策

新建独立 `tech-notes`，不修改同级旧文档或旧主页仓库。原生文章在 `content/`，Kalibr 正文留在源项目；构建时只读导入书籍子目录。用户已确认公开仓库及书籍全文发布。

## 同步范围

源仓库 `wangyendt/kalibr-camimu-ceres` 的 `master` 分支，仅 `docs/books/kalibr_cam_imu_from_equations_to_ceres`。不导入项目其余文件、不执行源码、不双向回写。

默认每小时检查，比较书籍目录树与本站构建输入的指纹；变化才部署。支持手动强制构建和未来的跨仓库事件，但默认不修改源仓库，也不申请额外令牌。

## 发布检查

严格构建、链接与匿名化检查、公式和导航浏览器验证通过后发布。正文保留证据等级、draft 状态和适用边界。不发布个人健康记录或原始诊断包。
